# Contract: 消费端动态路由（033）

## Windows 客户端（面板行为契约）

- 连接成功后立即 + 每 60s：刷新「可达宣告子网」并应用为隧道路径；**无需重连**即对新增/撤回生效（≤60s）。
- 面板新增「可达子网」区块：`替身网段 / 真实网段 / zone(s) / 宣告者`；冲突条目标注「冲突·已跳过」；API 失败时显示上次结果 + 刷新失败提示（路径冻结）。
- 断开：路径随隧道整体消失，系统路由零残留；重连自动重建。
- 兼容：无任何宣告时面板与连接行为与 032 前完全一致（零回归）。

## OpenWrt routerd（CLI/daemon 行为契约）

- daemon 对账循环（60s，032 既有）同轮维护消费路由：他人宣告的合成段 → server peer AllowedIPs ∪ 内核路由；自己宣告的合成段**不**配置（本地直达，避免回环）。
- `announce list` 增 `--all`（或等效区分展示）：

```
MINE   SUBNET            SYNTHETIC         ZONES    ANNOUNCER   RULES/ROUTE
yes    192.168.50.0/24   100.100.1.0/24    homelab  (this)      ok
no     10.8.0.0/24       100.100.2.0/24    homelab  bob-router  routed
```

- `status` 不新增字段（路由状态由 list 承载）；隧道 Down/logout 路径零残留。
- 单条冲突：跳过 + 日志告警，其余生效；下轮对账自动补上。

## 跨端一致性契约（FR-009）

同一账号同一 zones 状态下，Windows 与 routerd 得到**相同的合成段集合**（同一聚合逻辑共用，仅平台应用机制不同）。

## 刷新与失败语义（两端一致）

- 触发：连接/daemon 启动即一次；运行期 60s 周期；（routerd）隧道自愈重建后 ≤1 周期恢复。
- API 不可达：跳过本轮，既有路径冻结，恢复后收敛。
- 离开 zone / 宣告撤回：≤1 周期路径移除（窗口期流量已被服务端拦断，残留无害）。

## 回归契约

- 服务端零改动；`unshare -rUn bash -c 'ip link set lo up && go test ./...'` 全绿；031/032 命令零回归；Windows 既有连接/断开/自愈行为零回归。
